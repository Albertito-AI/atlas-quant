# Project operations manual

Revision 1

Use the following instructions when the recorded conditions apply.

## review-source-permissions

Before activating a source or materially changing its intended use, run the reviewed source-permission gate for the exact source plan. Check AI use, publication, attribution and commercial restrictions against current primary terms. Public access and a passed routing test confer no permission. Stop an unresolved or disallowed source; record the evidence and a permitted alternative.

Applies when task = activate-source.
Practice evidence (public-feed-rights-near-miss): Observed design near miss, 13 November 2026: public unauthenticated access was technically available, but current Coinbase terms section 3(5) restrict AI research without consent. No unauthorised ingestion occurred. See INCIDENT.md.
